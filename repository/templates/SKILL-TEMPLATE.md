## 工作流程

1. 从请求中确认目标和限制。
2. 检查相关现状，不猜测标识符或选项。
3. 执行范围最小的操作，并核验结果。

## 安装、更新和卸载

每个技能必须随目录提供 `scripts/install.sh`、`scripts/update.sh`、`scripts/uninstall.sh`、`scripts/verify.sh`。无独立安装资源时，复制 `repository/templates/scripts/` 下的默认脚本；有二进制、PATH 或运行时资源时，按仓库生命周期规范替换为对应实现。

说明本技能通过哪个 Skills 管理器安装和更新，如何验证，卸载脚本清理什么。技能文件更新后必须立即运行本技能的 `scripts/install.sh`，完成架构裁剪、PATH/运行时后处理。生命周期脚本从自身位置动态推导技能路径，不得写死安装目录；安装不复制或移动已有技能文件，通过 PATH 暴露原位置的命令。若适用，说明卸载不会影响哪些远端资源。
