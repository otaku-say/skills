# pv —— 管道流量监视器（进度/速率/ETA）

在任意管道中间插一枚"仪表盘"：经过多少字节、当前速率、预计剩余时间。
大文件拷贝、备份、下载、慢速传输的现场可视化。

## 推荐用法

```sh
# 1) 拷贝大文件（已知总大小 → 显示进度条 + ETA）
pv big.iso > /mnt/backup/big.iso
pv big.iso | dd of=/dev/disk2 bs=1M

# 2) 管道中继（未知总大小 → 用 -s 给它个参照）
tar cf - /data | pv -s $(du -sb /data | cut -f1) | gzip > data.tgz

# 3) 限速（-L 字节/秒；后缀 K/M/G）
pv -L 1m big.iso > slow-disk/big.iso

# 4) 只出数字（脚本里取值，人类不友好但可解析）
pv -n file > /dev/null 2>&1

# 5) 数个数的模式（按行计，适合日志）
cat big.log | pv -l -s 1000000 | grep ERROR > errors.log

# 6) 版本
pv --version       # pv 1.7.24
```

## 常用参数

| 参数 | 作用 |
|---|---|
| `-p` / `-t` / `-e` / `-r` / `-b` | 进度条 / 计时 / ETA / 速率 / 字节数 |
| `-n` | 数值输出（脚本可解析） |
| `-q` | 安静：什么都不显示 |
| `-s SIZE` | 预估总大小（显示百分比和 ETA 需要） |
| `-l` | 按行计数而非字节 |
| `-L RATE` | 限速（如 `1m` = 1MB/s） |
| `-W` / `-D SEC` | 有数据才显示 / 延迟显示 |
| `-F FORMAT` | 自定义输出格式（高级） |
| `-A NUM` | 显示最后写入的 NUM 字节 |

## 退出码 / 错误处理

- 0 成功；非 0 失败（打不开输入等）。
- 显示走 **stderr**（不污染被传输的数据流）——`pv file > out` 中进度照样看得见。

## iSH 注意事项

- 本套件为**自编译静态**；真机可用（管道/文件场景）。
- 无 TTY（脚本/Agent 环境）时进度条不刷新属正常；要数值用 `-n`。
- 慢设备限速与"边看边传"场景优先；纯本地小文件不值得套。

## 相关工具

- `xxhsum` —— 传输前后校验
- `scp` / `curl` —— 网络传输（它们自带进度；pv 管本地管道）
- `zstd` —— `zstd -c big | pv | ssh ...` 组合
