# fd —— 快速按名字/扩展名找文件（fd 10.5.0）

按正则或 glob 在目录树里找文件/目录条目，默认跳过隐藏项并遵守 ignore 规则，写起来比 find 短。
只按文件名找用它；搜文件内容用 rg，看目录结构用 tree。

## 推荐用法

```sh
# 名字含 test（默认智能大小写）
fd test

# 按扩展名 / 只找目录 / 只找文件
fd -e py
fd -t d
fd -t f

# 隐藏文件也显示；ignore 规则一律不算
fd -H
fd -I

# 全放开：-u = -I + -H（连隐藏一起）
fd -u

# 非 git 目录里也想让 .gitignore 生效
fd --no-require-git

# glob / 字面量模式
fd -g '*.js'
fd -F 'a(1)'

# 限制深度 / 结果数；绝对路径
fd -d 2
fd -u --max-results 5
fd -a

# 对每个结果执行命令
fd -e txt -u -x echo FOUND {}
```

## 常用参数

| 参数 | 作用 |
|---|---|
| `-H` | 包含隐藏项 |
| `-I` | 不读 ignore 规则 |
| `-u` | = `-I` + `-H`，更放开可重复 |
| `--no-require-git` | 非 git 仓库也读 .gitignore |
| `-e EXT` | 按扩展名（可多个） |
| `-t T` | 按类型：f/d/l 等 |
| `-d N` | 最大遍历深度 |
| `-g` | 模式按 glob 解释 |
| `-F` | 模式按字面量 |
| `-s` / `-i` | 大小写敏感 / 不敏感（默认智能） |
| `-a` | 输出绝对路径 |
| `-L` | 跟随符号链接 |
| `-x CMD` | 对每个结果执行命令（`{}` 占位） |
| `--max-results N` | 最多 N 个结果 |
| `-q` | 静默：只影响退出码 |

## 退出码

- 默认**无论有没有匹配都返回 0**（实测）。
- 想按退出码判断有无匹配：`fd -q PATTERN` —— 有匹配 0、无匹配 1（实测）。

## iSH 注意事项

- 找不到文件先想两件事：是不是隐藏文件（加 `-H`/`-u`）？是不是被 gitignore 挡了（加 `-I`）？
- **`.gitignore` 只在检测到 git 仓库时才默认生效**：实测无 `.git` 的目录里不生效；加 `--no-require-git` 强制生效。
- 默认退出码 0 掩盖「没找到」：脚本判空看输出或加 `-q`。
- 全静态 aarch64 二进制，不依赖 apk 包。

## 相关工具
