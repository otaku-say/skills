# pstree —— 进程树

以树形展示进程父子关系（psmisc 套件里的进程树工具）。排查"谁拉起了谁"、
守护进程族谱、残留子进程的现场第一眼工具。

## 推荐用法

```sh
# 1) 全树
pstree

# 2) 带 PID（排查时最常用）
pstree -p

# 3) 带完整命令行（看参数）
pstree -a

# 4) 只看某进程的子树（PID 或用户名）
pstree -p 1234
pstree root

# 5) 高亮当前进程及其祖先
pstree -h

# 6) 按属性着色（看进程年龄）
pstree -C age

# 7) 版本 / 帮助
pstree -V           # pstree (PSmisc) 23.7
pstree --help
```

## 常用参数

| 参数 | 作用 |
|---|---|
| `-p` | 显示 PID |
| `-a` | 显示命令行参数（默认只显示进程名） |
| `-h` / `-H PID` | 高亮当前进程 / 指定 PID 及其祖先 |
| `-g` | 显示进程组 ID |
| `-u` | 显示用户切换 |
| `-c` | 不压缩相同子树（-p 时自动开） |
| `-A` / `-G` / `-U` | ASCII / VT100 / UTF-8 画线（默认 UTF-8） |
| `-C TYPE` | 着色（如 `-C age`） |
| `-n` / `-N TYPE` | 按 PID / 属性排序 |
| `-V` | 版本 |

## 退出码 / 错误处理

- 0 成功；非 0 失败（找不到 PID/用户）。
- 数据源为 `/proc`：容器内只看到本容器可见的进程。

## iSH 注意事项

- 本套件为**自编译静态**（依赖链：ncurses→psmisc，仅交付 pstree 一个二进制）；
  真机可用（实测能正确显示 iSH 进程树）。
- iSH 的 `/proc` 比较简化：个别字段（如进程组细节）可能与 Linux 不完全一致。
- 与 busybox `ps` 互补：ps 看"平面清单"，pstree 看"血缘"。

## 相关工具

- `faketty` / `chronic` —— 组合进守候脚本做现场留存
