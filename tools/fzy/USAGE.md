# fzy —— 模糊查找器（交互 + 脚本两用）

极快的模糊匹配选择器：管道给它候选行，交互挑选或**脚本里按查询串直接拿结果**。
（`-e` 非交互模式对 Agent 特别有用：给个模式，直接输出排序后的全部命中。）

## 推荐用法

```sh
# 1) 交互式（终端里；需要 TTY）
ls | fzy
git ls-files | fzy -p 'file> '

# 2) 非交互：直接输出匹配行（Agent/脚本友好，无需 TTY）
ls | fzy -e 'py$'
find . -name '*.md' | fzy -e readme

# 3) 带打分（按相关度排序，分越高越靠前）
ls | fzy -s -e conf

# 4) 多行显示 + 指定条目数
ls | fzy -l 20 -e test

# 5) NUL 分隔输入（文件名含换行/空格时）
find . -name '*.c' -print0 | fzy -0 -e main

# 6) 版本 / 帮助
fzy --version      # fzy 1.1
fzy --help
```

## 常用参数

| 参数 | 作用 |
|---|---|
| `-e QUERY` | **非交互**：输出按相关度排序的全部匹配（脚本核心用法） |
| `-q QUERY` | 交互模式预设查询串 |
| `-s` | 显示匹配分数 |
| `-l N` | 交互模式显示行数（默认 10） |
| `-p PROMPT` | 交互提示符 |
| `-t TTY` | 指定终端设备（默认 `/dev/tty`） |
| `-0` | NUL 分隔输入 |
| `-j N` | 并行 worker 数 |
| `-h` / `-v` | 帮助 / 版本 |

## 退出码 / 错误处理

- 交互取消 → 非 0；`-e` 模式无匹配 → 空输出、非 0。
- 交互模式**需要 TTY**（从 `/dev/tty` 读键）：非终端环境（Agent 管道）请用 `-e`。

## iSH 注意事项

- 本套件为**自编译静态**（无需 ncurses）。真机可用。
- 纯字节匹配（不感知多字节编码）；对 UTF-8 内容按字节工作——日常筛选没问题。
- Agent 场景优先 `-e`：完全非交互、结果确定、可进管道。

## 相关工具

- `fd` —— 找文件（fzy 的常见上游：`fd | fzy -e ...`）
- `rg` —— 找内容
- `entr` —— 选中文件后自动重跑命令的搭档
