# rg —— 高速递归内容搜索（ripgrep 15.2.0）

在目录树里按正则搜索文件内容，默认跳过隐藏文件、二进制文件和 gitignore 命中的路径。
问「哪里出现了这个字符串/正则」用它；只按文件名或扩展名找文件用 fd，做替换用 sd。

## 推荐用法

```sh
# 递归搜当前目录（默认跳过隐藏、二进制、gitignore）
rg foo

# 忽略大小写 + 行号
rg -i -n hello

# 只列命中文件 / 每文件命中行数
rg -l foo
rg -c foo

# 只看某类型文件（--type-list 查全部类型，如 py: *.py）
rg -t py 'TODO'

# 找带正则特殊字符的字面量
rg -F 'a.b('

# 多模式 OR / 整词匹配
rg -e foo -e bar -l
rg -w foo

# 只输出匹配片段；给上下文
rg -o '[0-9]{3}' .
rg -C 2 foo

# PCRE2（前瞻/后顾）；本机二进制带 +pcre2
rg -P 'foo(?=bar)'

# 列出会被搜索的文件（不搜内容）
rg --files

# 连隐藏一起搜（-u 只取消 ignore，-uu 再加隐藏）
rg -uu -l foo
```

## 常用参数

| 参数 | 作用 |
|---|---|
| `-i` | 忽略大小写 |
| `-n` | 输出行号 |
| `-l` | 只列文件名 |
| `-c` | 每文件命中行数 |
| `-o` | 只输出匹配片段 |
| `-F` | 模式按字面量处理 |
| `-e PAT` | 指定模式，可多次（OR） |
| `-w` | 整词匹配 |
| `-t T` | 只看某类型文件（`--type-list` 查） |
| `-g GLOB` | 按 glob 过滤路径 |
| `-A/-B/-C N` | 后/前/上下 N 行上下文 |
| `-P` | 换用 PCRE2 引擎 |
| `-a` | 二进制文件也当文本搜 |
| `-u` | 放松过滤，可重复（-uu 含隐藏） |
| `--files` | 只列文件 |
| `-j N` | 线程数（默认自动） |

## 退出码

- `0` = 有匹配
- `1` = 无匹配（**不是错误**）
- `2` = 出错（路径不存在、正则非法等）

## iSH 注意事项

- **无匹配时退出码是 1**：脚本里写 `rg foo || true`，别把 1 当失败（实测无匹配 rc=1、目标不存在 rc=2）。
- 默认多线程正常；要固定输出顺序可加 `-j1`（实测可用）。
- `-P` 前瞻实测可用（`foo(?=bar)` 命中成功）；本机版本号带 `+pcre2`。
- 全静态 aarch64 二进制，不依赖 apk 包和网络。

## 相关工具

- `fd` —— 只找文件/目录名，不搜内容
- `sd` —— 找到后做正则替换
- `jaq` —— 处理 JSON 内容
