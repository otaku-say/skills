# entr —— 文件一变就执行命令

监视给定的文件列表，任一文件被改动就运行一次命令（跑测试、重编译、刷预览的标准件）。
用法范式：`ls *.c | entr make` —— 从 stdin 读文件名清单。

## 推荐用法

```sh
# 1) 改动 *.c 就跑测试（ls 先给"初速"，之后 entr 自己盯 inode）
ls *.c | entr -c make test
#    -c：每次执行前清屏

# 2) 盯目录内容增删（新文件出现也会触发）
ls -d src/* | entr -d make
#    -d：跟踪目录增删（v5.x 新能力）

# 3) 后台常驻 + 信号重启（适合放进脚本/长会话）
ls app.py | entr -r python app.py
#    -r：以子进程方式跑，收到信号时重启它

# 4) 非交互（Agent/CI 里跑）：配合头文件自读
find src -name '*.c' | entr -n sh -c 'make -s'

# 5) 执行完一次就退出（单次触发）
ls conf.yml | entr -z ./reload.sh

# 6) 版本 / 帮助
entr                # release: 5.9（裸执行打印版本与用法）
entr -h
```

## 常用参数

| 参数 | 作用 |
|---|---|
| `-c` | 执行前清屏 |
| `-d` | 跟踪目录内文件的增/删 |
| `-n` | 非交互模式（stdin 不接 TTY 时友好） |
| `-p` | 等第一次事件后再执行（不等首轮） |
| `-r` | 后台重启模式：收到信号时重启子进程 |
| `-s` | 用 shell 执行 utility（支持管道等） |
| `-x` | 格式化退出状态转发 |
| `-z` | 子进程退出后 entr 也退出（单次） |
| `-a` | 合并事件（不逐个 file 触发） |

## 退出码 / 错误处理

- 0 正常退出（如 -z 完成）；非 0 失败（无文件可监视等）。
- 子进程退出码默认不透传；要改造用 `-x`。

## iSH 注意事项

- 本套件为**自编译静态**（musl）；真机可用。
- **从 stdin 读文件名清单**（`ls *.c | entr ...`），不是从参数；空清单会直接退出。
- 监视的是 **inode**：很多编辑器"保存"会换 inode——若发现不触发，把
  `ls file` 重跑一次（或用目录模式 `-d`）。
- 交互式长跑建议配 `faketty`（行缓冲/彩显）或直接在终端里用。

## 相关工具

- `faketty` —— 给被监视命令伪终端语义（颜色/交互）
- `chronic` —— 把"每次触发"的输出降噪（成功静默）
- `tini` —— entr 挂掉时确保子进程被收割
